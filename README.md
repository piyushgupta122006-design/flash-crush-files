# Flash Crush-Files — Free PDF & Image Compressor & Converter

Fast, private, in-browser PDF & Image compressor and image format converter.

## Features
- **PDF Compressor**: Reduce PDF size by up to 80% with adjustable quality levels.
- **Image Compressor**: Canvas-based quality reduction and custom KB size targeting for JPG, PNG, and WebP.
- **Image Converter**: Convert between PNG, JPG, WebP, BMP, and GIF formats.
- **Google Drive Integration**: Direct import and save to Google Drive folders.
- **100% Client-Side**: No uploads to remote processing servers — all files remain on your device.

## Getting Started

```bash
npm install
npm run dev
```
